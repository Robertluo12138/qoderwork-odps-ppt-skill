# 淘宝闪购品牌 VI 规范

本文档记录淘宝闪购品牌视觉标准，供 PPT 渲染器和模板维护参考。

## 标准色

| 角色 | 色值 | RGB | CMYK | PANTONE | 占比 |
|---|---|---|---|---|---|
| 品牌色 | `#FF6200` | 255 / 98 / 0 | 0 / 75 / 92 / 0 | Orange 016C | **90%** |
| 辅助色 | `#FFA020` | 255 / 160 / 32 | 0 / 49 / 86 / 0 | — | **10%** |

## 衍生色（PPT 报告用）

| 用途 | 色值 | 说明 |
|---|---|---|
| 淡底填充 | `#FFF4EB` | 卡片背景、高亮区域底色 |
| 暖边框 | `#FFDCC8` | 卡片边框、分割线暖调 |
| 图表色阶 1 | `#FF6200` | 品牌主色 |
| 图表色阶 2 | `#FF8A3D` | 品牌色减淡 |
| 图表色阶 3 | `#FFA020` | 辅助色 |
| 图表色阶 4 | `#FFB85C` | 辅助色减淡 |
| 图表色阶 5 | `#FFDCC8` | 最浅层 |

## Logo 使用规范

- 优先在**白色背景**或**纯色背景反白**使用
- 背景色阶 30%~60% 区间**不可放置 Logo**
- 支持场景：白底正色、彩色反白、纯色反白、黑色反白、渐变反白
- Logo 文件：`assets/taobao_flash_sale_logo.png`（请替换为官方素材）

## 字体规范

| 平台 | 西文字体 | 中文字体 |
|---|---|---|
| macOS | Aptos | Hiragino Sans GB |
| Windows | Aptos | Microsoft YaHei |
| Linux | DejaVu Sans | Noto Sans CJK SC |

## 禁忌

- 不可修改品牌色色相
- 不可将 Logo 用于杂色背景（30%~60% 色阶区间）
- 不可拉伸或旋转 Logo
