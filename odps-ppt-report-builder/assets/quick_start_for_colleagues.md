# 首次使用

第一次在这台电脑上用，就先把下面这段发给 Qoder Work。

---

用 `odps-ppt-report-builder` 处理这次报告。

先不要直接开始做 PPT，先把下面几件事检查一下：

- 确认现在是 Qoder Work，不是 Qoder IDE
- 确认当前系统是 Mac 还是 Windows，只给当前系统对应的步骤
- 看一下 skill 文件夹有没有放对位置
- 看一下 `assets/company_private_brief.md` 在不在
- 看一下 `odpscmd` 能不能用
- 看一下这台机器有没有 Python

如果上面任何一项有问题，就先停在那一步，直接告诉我：

- 现在缺什么
- 我下一步只要做什么
- 做完以后我回你什么

不要一下子给我很多种方案，也不要让我自己猜下一步。

取数的时候只用私有说明里已经写好的 SQL 和规则，不要自己改。  
如果这台机器暂时还不能直接出 `.pptx`，那就先把完整讲稿和每页大纲整理出来，不要停在半路。

这次的需求是：

- 业务：`这里换成业务名`
- 时间范围：`这里换成时间范围`
- 报告类型：`这里换成周报 / 月报 / 复盘 / 经营分析`

最后回我这几样：

- 最终文件路径
- 3 到 5 条重点结论
- 如果没跑通，明确告诉我卡在哪一步
